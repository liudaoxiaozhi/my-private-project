# 小说

整本书放在这个文件夹里，按「卷 → 章」组织。写完保存，重新运行 `本地预览.bat` 就能在网站「小说」栏目看到。

## 文件结构

```
novel/
├── _book.md                    书的信息（必需）
├── 01. 第一卷 初醒/             一卷一个文件夹
│   ├── _volume.md              可选：卷的标题和简介
│   ├── 001. 第一章 醒来.md      一章一个文件
│   └── 002. 第二章 回声.md
└── 02. 第二卷 远行/
    └── 001. 第一章 出发.md
```

- **开头的数字决定顺序和网址**：`01` 卷的 `002` 章，网址是 `/novel/01/002`。之后改标题没关系，改数字会改变网址（读者收藏的链接会失效），所以发布后尽量别改数字。
- 每卷里的章号可以从 `001` 重新开始。
- 文件名里数字后面的文字就是标题；也可以在文件开头用 `title:` 单独写标题。

## _book.md（书的信息）

```markdown
---
title: "书名"
author: "笔名"                      # 可选；不写默认是站长，写 "" 则不显示署名
cover: "/images/novel/cover.webp"   # 可选，竖版封面，建议 600×800
status: "连载中"                    # 连载中 / 已完结 / 暂停更新
tags: ["科幻", "成长"]
---

这里写简介，可以写好几段。
```

## 每一章

```markdown
---
title: "第一章 醒来"      # 可选，不写就用文件名里的标题
date: "2026-10-07 20:00"  # 发布日期，会显示在目录里，并决定首页「最近更新」
draft: true               # 可选：写了这行就不会发布，适合存稿
---

正文直接写，段与段之间空一行。阅读器会自动首行缩进。

需要场景分隔时，单独一行写三个星号：

***
```
