# 书架（小说）

网站导航栏里的「书架」栏目：可以放多本书，按分类展示。写完保存，重新运行 `本地预览.bat` 就能看到。

书有两种：

- **可在线阅读的书**：有卷和章，读者在站内用沉浸式阅读器看（例如朋友的连载）。
- **书单条目**：只有 `_book.md`，没有章节。书架上照常显示封面和简介，书页上放一个外部链接（比如豆瓣），不提供正文。别人出版的书请用这种方式，不要把正文放进来。

## 文件结构

```
novel/
├── _shelf.md                       书架分类及顺序
├── chuanyue-mijing/                一本书一个文件夹
│   ├── _book.md                    书的信息（必需）
│   ├── 01. 第一卷 初醒/             一卷一个文件夹
│   │   ├── _volume.md              可选：卷的标题和简介
│   │   ├── 001. 第一章 醒来.md      一章一个文件
│   │   └── 002. 第二章 回声.md
│   └── 02. 第二卷 远行/
│       └── 001. 第一章 出发.md
└── foundation/                     书单条目：只有 _book.md
    └── _book.md
```

- **书的文件夹名就是网址里的书号**，建议用小写英文和连字符，例如 `chuanyue-mijing`。书页网址是 `/novel/chuanyue-mijing`。
- **卷和章开头的数字决定顺序和网址**：`01` 卷的 `002` 章，网址是 `/novel/chuanyue-mijing/01/002`。之后改标题没关系，改数字或书号会改变网址（读者收藏的链接会失效），所以发布后尽量别改。
- 每卷里的章号可以从 `001` 重新开始。
- 文件名里数字后面的文字就是标题；也可以在文件开头用 `title:` 单独写标题。
- 封面图放在 `public/images/novel/`，竖版 3:4 效果最好。

## _shelf.md（书架分类）

```markdown
---
categories: ["好友原创", "历史", "科幻"]
---
```

分类按这里的顺序显示。书的 `category` 没列在这里的，排在最后；没写 `category` 的归到「未分类」。

## _book.md（书的信息）

```markdown
---
title: "书名"
author: "笔名"                      # 可选；不写默认是站长，写 "" 则不显示署名
category: "好友原创"                 # 书架分类
cover: "/images/novel/xxx.webp"     # 可选，竖版封面；不写就用书名竖排的渐变书封
status: "连载中"                    # 连载中 / 已完结 / 暂停更新（只对可阅读的书显示）
tags: ["科幻", "成长"]               # 可选
publisher: "某某出版社"              # 可选，书单条目常用
link: "https://book.douban.com/…"   # 可选，书单条目的外部链接，书页上显示「在豆瓣查看」
---

这里写简介，可以写好几段。
```

## 每一章

```markdown
---
title: "第一章 醒来"      # 可选，不写就用文件名里的标题
date: "2026-10-07 20:00"  # 发布日期，会显示在目录里，并决定书页的「最近更新」
draft: true               # 可选：写了这行就不会发布，适合存稿
---

正文直接写，段与段之间空一行。阅读器会自动首行缩进。

需要场景分隔时，单独一行写三个星号：

***
```
