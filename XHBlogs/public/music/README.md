# 本地音乐

> 网易云的歌在网页后台「歌曲」里粘贴歌单 / 歌曲链接导入（存在 `data/netease.json`），排在这里的本地歌曲前面。

把音频文件放进这个文件夹，`npm run dev` / `npm run build` 时会自动生成歌单（`playlist.json`），无需改任何配置。

## 命名规则

```
01. YOASOBI - 夜に駆ける.mp3    音频（必需）：可选序号 + 「歌手 - 歌名」
01. YOASOBI - 夜に駆ける.lrc    歌词（可选）：与音频同名
01. YOASOBI - 夜に駆ける.jpg    封面（可选）：与音频同名，支持 jpg / jpeg / png / webp
```

- 开头的序号（`01.`、`02_`、`03)`）只决定播放顺序，不会显示。
- 没有「 - 」时，整个文件名作为歌名。
- 推荐 mp3（128–320 kbps）或 m4a；flac / wav 体积太大，ogg / opus 在旧版 Safari 上放不了。

## 内嵌信息

音频文件里自带的歌名、歌手、封面、歌词（ID3 / FLAC / M4A 标签）会被自动读取：

- 优先级：**同名文件 > 内嵌标签 > 文件名**。想替换某首歌的封面或歌词，放一个同名 `.jpg` / `.lrc` 即可。
- 内嵌歌词带时间轴（`[00:12.34]` 或同步歌词标签）时，网页上逐行滚动高亮；纯文本歌词只静态显示。
- 内嵌封面和歌词在构建时导出到 `_covers/`、`_lyrics/`，这两个目录是自动生成的，不用管，也不会提交到 Git。

## 播放顺序

按文件名排序（带序号时按序号）。任意一首加载失败会自动跳到下一首。
